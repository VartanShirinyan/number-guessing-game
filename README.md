# number-guessing-game

Простая консольная игра, написанная на Python, где компьютер загадывает число, а пользователь пытается его угадать.

## Как играть
1. Убедитесь, что у вас установлен Python 3.
2. Скачайте файл `game.py`.
3. Запустите скрипт в терминале: `python3 game.py`.
4. Следуйте инструкциям на экране.
